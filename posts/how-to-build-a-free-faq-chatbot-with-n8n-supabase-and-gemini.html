How to Build a Free FAQ Chatbot With n8n, Supabase, and Gemini

Nov 5, 2026 · 3 min read

A chatbot that answers customer questions from a business's own FAQ is one of the most requested jobs for small online shops. The good news is that you can build a working version with free tools. Here is the basic idea and the steps I followed.

What this chatbot does

A customer asks a question. The chatbot looks for the closest answer in your FAQ and replies using that information. If it cannot find an answer, it says it is not sure and offers to hand the conversation to a human. This keeps the bot honest instead of making things up.

What you need

- n8n (the free self-hosted version works)
- A free Supabase project
- A free Gemini API key from Google AI Studio
- A short FAQ list (10 to 20 questions is enough for a demo)

Step 1: Prepare your FAQ

Write your questions and answers in simple text. For a practice project, make up a small business, like a coffee shop, with questions about opening hours, prices, and delivery.

Step 2: Create a table in Supabase

Enable the vector extension, then create a table to hold your FAQ text and its embedding. The vector size in the table must match the size your embedding model produces, or the insert will fail.

Step 3: Load your FAQ into the database

Build a small n8n workflow that reads each FAQ row, creates an embedding with Gemini, and saves both the text and the embedding in Supabase. You only need to run this once, or again when your FAQ changes.

Step 4: Build the chat workflow

Create a new workflow with a Chat Trigger node and connect it to an AI Agent node. Add a Gemini chat model and a simple memory so the bot remembers the last few messages.

Step 5: Connect Supabase as a tool

Add the Supabase Vector Store as a tool for the agent. Use the same Gemini embedding model here as you used when loading the FAQ. Give the tool a clear name and description, like "faq_search", so the agent knows when to use it.

Step 6: Write a clear system prompt

Tell the agent to answer only from the FAQ results, to keep replies short and friendly, and to say it is not sure when nothing matches. Also tell it what to say when the customer asks for a human.

Step 7: Test it

Try three kinds of questions: one that is in your FAQ, one that is not, and one asking for a human. A good bot answers the first, admits it does not know the second, and offers a handoff on the third.

Things to watch out for

- Use the same embedding model for loading and searching, or your results will be poor.
- Free Gemini plans have daily limits, so do not spam test messages.
- Keep your API keys private and never paste them into public code.
- Keep your FAQ clear and short, because the answers are only as good as your data.

Make it part of your portfolio

Record a short screen video showing the three test questions. Clients love seeing a bot work in 30 seconds, and a demo like this shows you can handle a real support chatbot job from start to finish.
