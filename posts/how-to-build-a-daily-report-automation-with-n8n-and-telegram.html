How to Build a Daily Report Automation With n8n and Telegram

Nov 14, 2026 · 4 min read

A daily report is one of the most useful small automations. Instead of opening a spreadsheet every morning to count new leads or orders, you get a short message on your phone. It is also a nice service to offer to small businesses, because owners love seeing the key numbers without searching for them. This guide shows how to build one with n8n, Google Sheets, and Telegram.

What you need

- An n8n workflow (self-hosted or cloud)
- A Google Sheet with some data, for example a list of leads with a date column and a status column
- A Telegram bot and your chat ID (you can create a bot with BotFather)

The idea

A schedule starts the workflow every morning. n8n reads the rows from your sheet, counts what you care about, builds a short message, and sends it to Telegram.

Step 1: Add a Schedule Trigger

Create a new workflow and add a Schedule Trigger node. Choose to run every day at a fixed hour, for example 8 in the morning. Check the timezone setting of your n8n instance or workflow, because a wrong timezone is the most common reason a report arrives at the wrong hour.

Step 2: Read the data from Google Sheets

Add a Google Sheets node and choose the action to get rows. Connect your Google account, pick your spreadsheet and sheet, and test it. You should see your rows appear as items in the output. If your sheet is very large, you can use a filter so n8n only reads the rows you need.

Step 3: Combine and count

n8n handles each row as a separate item, and you want one report. Add a node that turns the rows into one result. The Aggregate node can combine the items into a list. Then a Code node or a few simple steps can count things like the number of new leads, or the number of rows where the status is "new."

If you are new to code, keep it very small. For example, count the rows and put the result into a field called total. You can also ask an AI tool to help you write the few lines, and then test the output carefully.

Step 4: Build the message

Add an Edit Fields node and create a field named message. Use n8n expressions to insert your numbers into a short text. A good report is short and easy to read, like this:

Daily report: 5 new leads, 2 follow-ups due today, 1 order waiting.

Do not send a long wall of text. Three or four numbers are enough.

Step 5: Send it to Telegram

Add a Telegram node and choose the action to send a message. Select your credentials, paste your chat ID, and place the message field in the text box. Save the credentials in n8n instead of pasting your bot token inside the workflow, and never share the token publicly.

Step 6: Test it

Use the manual test button first. You should receive a Telegram message within seconds. If nothing arrives, check three things: the bot token, the chat ID, and whether you started a chat with your bot by pressing Start.

Step 7: Activate the workflow

When everything works, switch the workflow to Active. From now on, the schedule will run by itself every day. Check the executions list after the first morning to make sure it worked.

Ideas to improve it

- Add the date to the message
- Send a different message when the number is zero, such as a friendly note that there are no new leads
- Add a link that opens the Google Sheet
- Send the report to a group so a whole team can see it
- Add a weekly summary on Monday
- Add an error alert, so you get a message if the workflow fails

Common problems

- The report arrives at the wrong time: check the timezone settings
- The numbers are wrong: check the column names and make sure dates and statuses in the sheet are written in a consistent way
- Many messages arrive at once: your workflow may be running once per row instead of once per report, so make sure you combine the items before the Telegram node
- Google Sheets cannot connect: reconnect your Google account and check that the sheet is shared with it

Turn it into a portfolio piece

Record a short screen video that shows the sheet, the workflow, and the message arriving on your phone. Add it to your portfolio and mention it in proposals for small business automation jobs. A working demo that solves a real, simple problem is often more convincing than a long list of skills.

Final thoughts

A daily report workflow teaches the core pattern of most automations: a trigger starts the process, data is collected, something is calculated, and a message is sent. Once you understand that pattern, you can adapt it for sales numbers, support tickets, social media stats, or anything else a client wants to follow.
