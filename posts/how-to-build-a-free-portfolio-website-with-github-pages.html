How to Build a Free Portfolio Website With GitHub Pages

Oct 26, 2026 · 3 min read

A portfolio website lets clients see your work in one place. It doesn't have to be fancy, and it doesn't have to cost money. With GitHub Pages you can publish a simple site for free, and you own all the files.

In this tutorial we'll put a basic portfolio online, step by step. You don't need to be an expert, but a little HTML helps.

What you need

1. A free GitHub account (sign up at github.com)
2. A text editor, such as Notepad or VS Code
3. About twenty minutes

Step 1: Create a repository

A repository (or "repo") is a folder on GitHub that holds your files.

1. Log in to GitHub and click the "+" button at the top, then "New repository".
2. Give it a name, for example my-portfolio.
3. Choose "Public". GitHub Pages is free for public repositories.
4. Click "Create repository".

If you name the repository exactly yourusername.github.io (using your real username), your site will live at the shorter address https://yourusername.github.io/. Any other name will put it at https://yourusername.github.io/repository-name/.

Step 2: Write your page

On your computer, create a file called index.html. The name matters, because GitHub Pages looks for this file first. Paste in this starter code:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Your Name | Freelancer</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 700px; margin: 40px auto; padding: 0 20px; line-height: 1.6; color: #222; }
    h1 { margin-bottom: 0; }
    .project { border-top: 1px solid #ddd; padding: 16px 0; }
    a { color: #2f5bff; }
  </style>
</head>
<body>
  <h1>Your Name</h1>
  <p>Freelance web developer who builds fast, simple websites for small businesses.</p>

  <h2>Projects</h2>
  <div class="project">
    <h3>Project name</h3>
    <p>What the problem was, what you built, and the result.</p>
    <a href="https://example.com">View project</a>
  </div>

  <h2>Contact</h2>
  <p>Email: <a href="mailto:you@example.com">you@example.com</a></p>
</body>
</html>

Change the name, the description, the project, and the email to your own details.

Step 3: Upload the file

1. Open your new repository on GitHub.
2. Click "Add file", then "Upload files".
3. Drag in your index.html file.
4. Scroll down and click "Commit changes".

Step 4: Turn on GitHub Pages

1. In your repository, click "Settings".
2. In the left menu, click "Pages".
3. Under "Branch", choose main, keep the folder as root, and click "Save".
4. Wait a few minutes, then refresh the Pages screen. GitHub will show the link to your live site.

Open the link, and your portfolio is online.

What to put in your portfolio

Clients don't want a long life story. They want proof that you can solve their problem. For each project, show three things:

1. The problem: what the client or project needed
2. What you did: the tools and steps, in plain words
3. The result: what changed, with a number if you have one

If you don't have client work yet, include personal projects, and label them clearly as personal projects. A working website or bot that you built yourself is still real proof.

Troubleshooting

1. You see a 404 page: check that the file is named exactly index.html (all lowercase) and sits in the main folder, not inside another folder.
2. Your changes don't show: wait a minute or two, then refresh with Ctrl+Shift+R.
3. The Pages option is missing or greyed out: make sure the repository is public.
4. Your site looks broken on a phone: check that the viewport line in the head of your code is still there.

Next steps

1. Add a photo, links to your Upwork profile, and your best three projects.
2. Move the CSS into its own style.css file as your site grows.
3. Buy a custom domain later, and connect it in the Pages settings.
4. Keep the site updated. Add a new project after each finished job.

The bottom line

You don't need a big budget to look professional online. A clean, simple page with real projects and a clear way to contact you is enough to start. Publish it today, and improve it a little every week.
