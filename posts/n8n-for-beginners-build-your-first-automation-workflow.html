n8n for Beginners: Build Your First Automation Workflow

Nov 1, 2026 · 2 min read

Automation jobs are everywhere on Upwork, and n8n comes up again and again. When I started learning it, I wanted a simple way to practice before applying to jobs. This is how I got my first workflow running, step by step.

What is n8n?

n8n is a tool where you connect blocks, called nodes, to make things happen automatically. For example: when someone fills out a form, save their details to a spreadsheet and send an email. You drag the nodes, connect them, and test.

Why learn it as a freelancer?

Many small businesses want to save time on boring tasks like lead forms, follow-up emails, and support replies. If you can build these flows, you have a skill clients ask for. It also looks good in a portfolio.

How I run it on my PC

I run n8n locally on my Windows PC. You need Node.js installed first. Then open PowerShell and run:

npx n8n

Wait until it starts, then open http://localhost:5678 in your browser. Create your owner account and you are in. Your workflows run on your own computer, so they only work while n8n is running.

My first workflow

My first real workflow had four nodes:

1. Webhook (POST): receives data, like a name and email, sent from a form.
2. Edit Fields: cleans up the data and keeps only what I need.
3. If: checks a condition, for example whether the message has an email address.
4. Google Sheets (Append): saves the row into a spreadsheet.

That small flow already looks like real client work: a lead comes in, gets checked, and gets saved.

How to build yours

1. Create a new workflow and add a Webhook node.
2. Add an Edit Fields node and set the values you want to keep.
3. Add an If node with a simple rule.
4. Connect Google Sheets and choose Append Row.
5. Click Test workflow and send sample data to the webhook.
6. Check your sheet. If the row appears, it works.

Mistakes to avoid

- Do not skip testing each node one by one. Find errors early.
- Never share your credentials, API keys, or webhook URLs in public.
- Remember that a local n8n stops when your PC or terminal closes. For real clients, you would host it online.

What to do next

Once the basic flow works, add an AI step. For example, send the message to an AI model and save the summary or score in your sheet. That turns a simple automation into something clients will pay for.

Start small, finish one working flow, and save a screenshot for your portfolio. One finished project teaches more than ten tutorials.
