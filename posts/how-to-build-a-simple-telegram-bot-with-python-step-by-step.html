How to Build a Simple Telegram Bot With Python (Step by Step)

Oct 25, 2026 · 4 min read

A Telegram bot is a small program that lives inside Telegram and replies to messages. People use them for customer support, reminders, notifications, and simple AI assistants. They are also a great first project if you want to learn how to build something real.

In this tutorial we will build a simple bot that greets you and repeats whatever you type. It is small, but it is the same foundation that bigger bots are built on. These steps are written for Windows, but they work on Mac and Linux with small changes.

What you need

1. A free Telegram account.
2. Python installed on your computer.
3. A text editor, such as Notepad or VS Code.

Step 1: Create your bot with BotFather

BotFather is Telegram's official bot for making bots.

1. Open Telegram and search for @BotFather. Make sure it has the blue verified check.
2. Send the message /newbot.
3. Choose a display name, for example "My First Bot".
4. Choose a username. It must end with "bot", for example myfirst_test_bot.
5. BotFather replies with a token, a long text that looks like random letters and numbers.

Treat this token like a password. Anyone who has it can control your bot. Never post it publicly or upload it to GitHub.

Step 2: Install Python

Download Python from python.org and run the installer. On the first screen, tick the box that says "Add Python to PATH". This is the step beginners most often miss.

When it finishes, open PowerShell and check that it worked:

python --version

You should see a version number. If you see an error, close PowerShell, open it again, and try once more. If it still fails, reinstall Python and make sure the PATH box is ticked.

Step 3: Install the Telegram library

In PowerShell, run:

pip install python-telegram-bot

This installs a library that handles all the hard parts of talking to Telegram for you.

Step 4: Write the bot

Create a new folder, for example mybot. Inside it, create a file called bot.py and paste in this code:

import os
from telegram import Update
from telegram.ext import (
    ApplicationBuilder,
    CommandHandler,
    MessageHandler,
    ContextTypes,
    filters,
)

TOKEN = os.environ["BOT_TOKEN"]


async def start(update: Update, context: ContextTypes.DEFAULT_TYPE):
    await update.message.reply_text("Hi! I'm your first bot.")


async def echo(update: Update, context: ContextTypes.DEFAULT_TYPE):
    await update.message.reply_text("You said: " + update.message.text)


app = ApplicationBuilder().token(TOKEN).build()
app.add_handler(CommandHandler("start", start))
app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, echo))

print("Bot is running...")
app.run_polling()

Here is what each part does:

1. The token is read from an environment variable called BOT_TOKEN, so the secret never sits inside your code file.
2. The start function runs when someone sends /start.
3. The echo function replies to any normal text message with the same text.
4. run_polling keeps the bot running and checking Telegram for new messages.

Step 5: Run it

Open PowerShell, go to your folder, set your token for this session, and start the bot. Replace the text in quotes with your real token:

cd path\to\mybot
$env:BOT_TOKEN = "PASTE_YOUR_TOKEN_HERE"
python bot.py

When you see "Bot is running...", open Telegram, find your bot by its username, and send /start. Then type any message. Your bot should reply.

The token you set in PowerShell lasts only until you close that window. That is fine for learning, and you will need to set it again next time.

Troubleshooting

1. "Unauthorized" error: the token is wrong or has extra spaces. Copy it again from BotFather.
2. The bot doesn't reply: make sure bot.py is still running in PowerShell. If you close the window, the bot stops.
3. "pip is not recognized": Python was not added to PATH. Reinstall it with the PATH box ticked.
4. A strange error right after installing: try updating the library with pip install --upgrade python-telegram-bot.

Where to go next

Once your echo bot works, you can make it genuinely useful:

1. Add more commands, such as /help or /about.
2. Connect it to an AI service so it can answer questions instead of repeating them.
3. Store messages or user data in a database.
4. Host it on a server so it stays online when your computer is off.

Each of these is a small step on top of what you just built. Many freelancers earn their first clients by building exactly this kind of bot for small businesses, so it is worth practicing.

The bottom line

You just built a working bot with about twenty lines of code. Keep your token secret, change one thing at a time, and test after every change. That habit will take you much further than any single tutorial.
