How to Back Up Your n8n Workflows So You Never Lose Your Work

Nov 24, 2026 · 2 min read

After you spend hours building an n8n workflow, losing it would hurt. A simple backup habit takes only a minute and can save your whole project. Here is how to do it.

1. Export a single workflow

Open the workflow, click the menu near the top of the editor, and choose the download option. n8n saves the workflow as a JSON file. This file contains the nodes, their settings, and how they connect.

2. Name the file clearly

Rename the file so you know what it is and when you saved it, for example lead-sorter_2026-11-24.json. If you keep several versions, you can go back when something breaks.

3. Know what the export does not include

An exported workflow does not include your saved credentials, such as your Google or Telegram login details. After you import a workflow on a new setup, you will need to connect those credentials again. This is a safety feature, so your passwords do not travel inside the file.

4. Import it again to test

A backup is only useful if it works. Create a new empty workflow and import your file, or use the import option from the menu. Check that the nodes appear and that the connections look right. Do this test once, so you are not surprised on a bad day.

5. Back up everything from the command line

If you run n8n yourself, there is also a command that exports all workflows at once. Check the n8n documentation for the exact command and options, because they can change between versions.

6. Keep a backup folder

Put your exported files in a folder such as C:\Freelance\n8n-backups. Add a short text file called README.txt that says which workflow does what.

7. Do not store secrets in the files

Even though credentials are not exported, a workflow can still contain private values that you typed directly into a node, such as an API key or a private address. Check the file before you share it or upload it to GitHub, and remove anything private.

8. Back up before big changes

Before you change a working workflow for a client, export a copy first. If your change breaks something, you can restore the old version in minutes.

9. Make it a habit

Pick one moment, for example every time you finish a project or every Friday, and export your workflows. Copy the backup folder to another drive or a private cloud folder, so one broken computer cannot take everything.

Good automation is not only about building. It is also about protecting what you built, so your clients and your time stay safe.
