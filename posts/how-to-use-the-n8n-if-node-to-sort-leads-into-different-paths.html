How to Use the n8n If Node to Sort Leads Into Different Paths

Nov 23, 2026 · 3 min read

A workflow that only moves data from one place to another is useful. A workflow that can make a decision is much more useful. In n8n, the If node is the simplest way to do that. In this tutorial, we will sort new leads by budget: big leads go one way, small leads go another way.

1. The plan

We will build four steps:

- A Webhook node that receives a lead (name, email, budget)
- An Edit Fields node that keeps only the data we need
- An If node that checks the budget
- Two Google Sheets nodes, one for big leads and one for normal leads

2. Add the Webhook node

Add a Webhook node and set the method to POST. Give it a simple path, such as lead. n8n shows two URLs: a Test URL and a Production URL. The Test URL works only while you click "Listen for test event." The Production URL works after you activate the workflow. Use the Test URL while you build.

3. Send a test lead

With n8n running on your computer, you can send a test lead from PowerShell:

Invoke-RestMethod -Method Post -Uri "http://localhost:5678/webhook-test/lead" -ContentType "application/json" -Body '{"name":"Ana","email":"ana@example.com","budget":800}'

The data should appear in the Webhook node. If nothing appears, check that the node is still listening and that the path matches.

4. Clean the data with Edit Fields

Add an Edit Fields node after the Webhook. Create fields called name, email, and budget, and take their values from the incoming data. This step is optional, but it keeps your workflow tidy and makes later steps easier to read.

5. Add the If node

Add an If node. Create one condition: the value is the budget field, the operation is Number > Is greater than or equal to, and the second value is 500. The If node has two outputs: true and false. Leads with a budget of 500 or more leave through true, and all others leave through false.

6. Connect both paths

Connect the true output to a Google Sheets node that appends a row to a sheet called High Priority. Connect the false output to another Google Sheets node that appends a row to a sheet called Normal. Use the same fields in both so your sheets look consistent.

7. Test both paths

Send one lead with a budget of 800 and one with a budget of 100. Check that each one appears in the right sheet. Always test both outputs, because it is easy to connect only one.

8. Common mistakes

- The budget arrives as text instead of a number. If the condition fails, check the data type, or fix it in Edit Fields.
- A lead arrives without a budget field. Decide what should happen, and add a condition for it if needed.
- Only the true output is connected, so the false leads disappear without any error.
- You forgot to activate the workflow, so the Production URL does not work.

9. Where to go next

Once you understand the If node, you can sort by country, by service type, or by keywords in a message. You can also send high-priority leads a Telegram alert while normal leads only go to a sheet. One small decision makes a simple workflow feel like a real business tool.
