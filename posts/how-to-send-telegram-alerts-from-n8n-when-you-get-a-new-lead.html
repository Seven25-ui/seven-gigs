How to Send Telegram Alerts From n8n When You Get a New Lead

Nov 12, 2026 · 3 min read

One of the most useful small automations you can build is an alert on your phone. When a new lead, order, or message arrives, you get a Telegram notification right away. It is simple, it works on any phone, and it is a feature many small business owners are happy to pay for. This guide shows the basic steps using n8n and a Telegram bot.

What you need

- An n8n workflow (self-hosted or cloud)
- A Telegram account
- Something that triggers the alert, such as a webhook, a form, or a Google Sheets change

Step 1: Create a Telegram bot

Open Telegram and search for BotFather, the official bot for creating other bots. Send the command /newbot and follow the questions. You will choose a name and a username that ends with "bot." At the end, BotFather gives you a token. This token works like a password for your bot, so keep it private and never post it in public.

Step 2: Start a chat with your bot

Search for your new bot in Telegram and press Start. The bot can only message you after you have started a conversation with it. If you want alerts in a group, add the bot to the group first.

Step 3: Find your chat ID

n8n needs to know where to send the message. The simplest way is to use a Telegram Trigger node in a test workflow, send a message to your bot, and read the chat ID from the data that arrives. The chat ID is a number that identifies you or your group.

Step 4: Add your credentials in n8n

In n8n, create new Telegram credentials and paste your bot token. Save it. n8n stores it safely, so you do not need to place the token inside your workflow nodes.

Step 5: Build the workflow

Create a new workflow and start with your trigger, for example a Webhook node that receives form data. Then add a Telegram node and choose the "Send Message" action. Select your credentials, paste your chat ID, and write the message.

Step 6: Use data from the trigger

A good alert includes details. In the message field, you can insert values from the previous step with n8n expressions. For example, your message could include the name, email, and message of the new lead. Keep it short and easy to read, like:

New lead: name, email, and a one-line message.

Step 7: Test it

Click the test button and send a sample request to your webhook. You should receive a Telegram message within seconds. If nothing arrives, check three things: the token, the chat ID, and whether you pressed Start in the chat with your bot.

Step 8: Activate the workflow

When everything works, switch the workflow to Active and use the production webhook URL in your form. From now on, every new lead will send you an alert automatically.

Ideas to improve it

- Send alerts to a group so a whole team can see them
- Add a simple check so you only get alerts for valid leads
- Include a link that opens the row in Google Sheets
- Send a different alert for urgent messages
- Add a second step that also saves the lead to a spreadsheet

Common problems

- Bot does not send: make sure you started the chat with the bot first
- Wrong chat ID: group IDs often start with a minus sign, so copy the whole number
- Token leaked: if you shared your token by mistake, create a new one in BotFather and update your credentials

Final thoughts

A Telegram alert workflow only takes a few minutes to build, but it shows clients that you can connect real tools and solve a real problem. Record a short screen video of the alert arriving, add it to your portfolio, and use it as a simple example in your Upwork proposals.
