How to Rename Files in Bulk With a Small Python Script on Windows

Nov 23, 2026 · 4 min read

Renaming many files by hand is slow and easy to get wrong. A short Python script can do it in a second. This tutorial shows a safe version that renames every .txt file in a folder to file_001.txt, file_002.txt, and so on. It keeps the extension and never overwrites a file. I tested it on my own Windows PC, and I show the real result below.

1. What you need

Python installed on your computer. To check, open PowerShell and type:

python --version

If you see a version number, you are ready. If not, install Python from python.org first.

2. Make a safe test folder

Never test on important files. Create a test folder with fake files:

mkdir C:\test_rename
cd C:\test_rename
"zebra","apple","mango" | ForEach-Object { Set-Content "$_.txt" "hello $_" }
Set-Content keep.md "this file should not change"

You now have three .txt files and one .md file. The .md file is there to prove that the script only touches .txt files.

3. Save the script

Open Notepad, paste the code below, and save it as C:\rename.py:

import sys, uuid
from pathlib import Path

folder = Path(sys.argv[1]) if len(sys.argv) > 1 else Path.cwd()
files = sorted(p for p in folder.iterdir() if p.is_file() and p.suffix.lower() == ".txt")
width = max(3, len(str(len(files))))

# Step 1: temporary names, so one file can never overwrite another
temps = []
for p in files:
t = p.with_name(f"{uuid.uuid4().hex}.tmp")
p.rename(t)
temps.append(t)

# Step 2: final sequential names
for i, t in enumerate(temps, 1):
t.rename(folder / f"file_{i:0{width}d}.txt")

print(f"Renamed {len(temps)} files.")

4. Run it

python C:\rename.py C:\test_rename
dir C:\test_rename

You should see file_001.txt, file_002.txt, and file_003.txt, plus keep.md untouched. The files are numbered in alphabetical order of their old names.

5. What my own test looked like

Before I ran the script, my test folder had four files: apple.txt, mango.txt, and zebra.txt (13 bytes each), and keep.md (16 bytes).

I ran the script and it printed: Renamed 3 files.

After that, the folder had file_001.txt, file_002.txt, and file_003.txt (13 bytes each), and keep.md was still there with 16 bytes. Because the script sorts the names alphabetically, apple went first, then mango, then zebra. The file sizes did not change, which told me the contents were not damaged, and the .md file was left alone, exactly as planned.

6. Why two steps?

Imagine a folder that already has a file called file_001.txt. If the script renamed straight to the final names, it could overwrite that file. By renaming everything to random temporary names first, no final name can collide with an old one. This is a small trick, but it makes the script much safer.

7. Why the width line?

The line with width makes the numbers at least three digits (001, 002). If you have more than 999 files, it uses more digits automatically, so the sorting still looks right.

8. Run it twice

Run the same command again. The script should still say it renamed 3 files, and you should still see file_001 to file_003. Nothing is lost, because the old names are simply replaced with the same final names.

9. If something goes wrong

- "python is not recognized": Python is not installed, or it was not added to PATH. Try the command py instead of python. If that also fails, reinstall Python and tick the option that adds it to PATH.
- Permission error: a file may be open in another program, such as Notepad or Word. Close it and run the script again.
- "Renamed 0 files": the folder has no .txt files, or you pointed to the wrong folder. Check the path.
- A folder path with spaces: put the path in quotes, for example python C:\rename.py "C:\My Files\notes".

10. Make it your own

If you want to rename another file type, change ".txt" in two places: the filter line and the final rename line. You can also change the word file_ to another prefix, such as invoice_ or photo_.

11. Before you give this to a client

- Make a copy of the real folder first, because the script renames ALL .txt files in it.
- Test it on a fake folder, as shown above.
- Write the run instructions in three short steps, so a non-technical person can follow them.

When you are done testing, delete the test folder with:

Remove-Item C:\test_rename -Recurse

That is the whole script. Small tools like this are a good way to practice Python and to build something you can actually use.
